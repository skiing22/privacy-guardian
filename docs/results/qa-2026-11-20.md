# QA report: 2026-11-20 (step 14)

Scope: everything built so far. The backend (API, worker, storage, crypto, model delivery)
and the web app's login, route guards and shell. Screens S2 to S6 do not exist yet; their
tests come with them (P14 to P18).

## Strategy

Priority follows the business risk in PRD 6: a document must never leave with personal
data still in it, one user must never see another's data, and the output must stay
usable.

| Level | What | Where |
| --- | --- | --- |
| Unit and property | Detectors, fusion, policy, crypto, output rebuild; Hypothesis for invariants | `backend/tests/` |
| Integration | Real SQLite, real graph, fake NER: every endpoint, the authorization matrix, failures | `test_api_*`, `test_authz`, `test_qa_edges` |
| Container | Image with a tiny random model: secret scan, then a real scan through HTTP | CI `docker` job, `scripts/smoke.sh` |
| Real model | Private model from Hugging Face, hash checked, real scan | CI `docker-real-model` (main only) |
| Frontend | Guards, login errors, session expiry, logout, safe redirects | Vitest |
| Browser (manual this round) | Login journey, cookie flags, 5 widths, touch targets, keyboard order | Playwright script, not committed |

Exploratory testing went first (14 probes on the riskiest paths); every bug found
became a regression test, and each test was checked to **fail on the old code**.

## Checked, working

- Same person in two scans: deleting one keeps the vault entry the other still needs.
- Locked database: `503 busy` with `Retry-After`, nothing half written.
- Disk full on upload: `503 storage_unavailable`, no scan row, no file.
- Model crash mid scan: `failed` with a generic message (no internal details), Retry finishes the scan.
- Deleting a paused scan also deletes its saved progress (which holds document text).
- Review answers "Not personal data" and a type correction are applied.
- `X-Forwarded-For` cannot dodge the login lockout when no proxy is trusted.
- General limit (120 per minute) applies to finished scans; polling open scans is exempt.
- File names: path parts stripped, 255 characters max, `a‮txt.exe` refused.
- Logs and audit records hold no document text, values or passwords (full scan checked).
- No horizontal scrolling at 320, 390, 768, 1024 and 1440 px; visible focus ring; login
  tab order email, password, Log in; empty submit focuses the first error.
